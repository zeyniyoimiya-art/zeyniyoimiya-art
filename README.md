## Diseño primero, código después

Diseño la interfaz **antes** de programarla y la programo **sin plantillas**. Me obsesionan los detalles que casi nadie ve: la tipografía que respira, el foco del teclado en jade, la animación que se apaga sola cuando el sistema pide movimiento reducido, el *service worker* que deja el sitio vivo sin conexión.

> Una web se **diseña**, no se decora.

## Lo que hago

| Área | Detalle |
| --- | --- |
| **Diseño de interfaz** | Sistemas de diseño propios, tipografía editorial (serif + CJK), retícula, jerarquía, color, modo claro/oscuro, estados de foco, prototipado |
| **Frontend** | HTML5 semántico, CSS moderno (grid, `clip-path`, `writing-mode`, container queries), TypeScript, React 19, Vite, Tailwind CSS v4 |

| **Calidad y datos** | Zod, Vitest, Playwright (e2e), Core Web Vitals, PWA offline, SEO (sitemap, RSS, Open Graph), accesibilidad (ARIA, teclado, contraste) |
| **Servidor y automatización** | Supabase (SQL + RLS + Edge Functions), Rust → WebAssembly, Web Audio API, GitHub Actions (CI + deploy) |

## Cómo trabajo

- **Accesibilidad real:** navegación por teclado, ARIA, contraste y respeto a `prefers-reduced-motion` (quien pide menos movimiento no recibe WebGL, partículas ni cursor especial).
- **Rendimiento medido:** imágenes diferidas, CLS 0, builds de ~300 KB gzip y un solo archivo cuando el proyecto lo pide.
- **Movimiento con sentido:** cada animación explica algo; ninguna está ahí solo para llamar la atención.
- **Sin plantillas:** cada proyecto se diseña y se escribe desde cero, y se publica con CI/CD.
